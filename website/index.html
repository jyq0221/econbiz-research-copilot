围绕研究问题，往前走一步

从模糊的想法，
到有依据的判断。

刚开始做研究，或正在推进多个项目，都能从当前最需要解决的问题切入。

01 / 研究设计

把方向变成可研究的问题

从兴趣或老师的反馈出发，比较研究问题、指标与方案，说明各自需要什么证据。

“数字化与经营风险，怎么缩小题目？”
02 / 文献与证据

读懂定义，也看清适用范围

对照论文的概念、测量和方法，把文献中的做法映射到自己的研究问题与数据字段。

“这篇论文的指标适合我的样本吗？”
03 / 数据准备

先看清数据，再开始分析

接入 Excel / CSV，检查重复、缺失和合并损失；按明确口径处理变量，保留原值与记录。

“加了控制变量，样本为什么少了？”
04 / 实际分析

从研究方案，走到实际结果

结合问题编写并运行 Python 或 Stata 代码。内置描述统计、固定效应分析与独立数值复核。

“按确认的模型执行，保留样本变化。”
05 / 结果与交付

讲清结果，也交出完整材料

结合方向、幅度和区间解释发现，比较模型与样本，整理为可编辑的 Word、LaTeX 和 PDF。

“这张表说明什么？帮我整理成报告。”
06 / 保存与接续

隔一段时间，也能接着做

按项目保存文献、数据、方案与决定。保留旧版本和修改理由，从有效记录恢复下一步。

查看项目完整说明
这是一个可以直接在线聊天的网站吗？+

这是经管研究 Copilot 的项目介绍页。实际研究在你配置的 Agent 环境中进行：本项目提供研究流程、Skills、分析工具和文件记录，AI 助手与模型服务由你的环境提供。

不会编程，也能使用吗？+

你可以用自然语言说明问题，让助手检查环境、解释方案并完成受支持的操作。不需要先记住命令或技能名称；研究中的概念、测量与关键选择，仍需要结合材料理解和判断。

没有 Stata，可以完成分析吗？+

可以。默认使用 Python 完成分析，内置描述统计和企业 / 年度固定效应可进行独立数值复核。Stata 为可选，当前原生路径实测 macOS arm64 与 Stata 19。

能做哪些分析，交付什么文件？+

可以根据研究问题处理数据、编写并执行 Python / Stata 项目脚本。内置核验覆盖描述统计和线性固定效应；其他方法按实际检查范围记录。结果可整理为 HTML、CSV、Word、LaTeX 和 PDF，PDF 编译需要可用的 XeLaTeX 环境。

研究记录和数据保存在哪里？+

研究材料保存在你指定的项目目录，或默认的 research-projects/项目标识/ 中，包含文献、数据和研究记录。接续以实际保存的文件为依据。模型调用时的数据处理方式取决于你选择的 Agent 与服务配置。

如何看待结果和“独立复核”？+

独立复核用于核对样本、设定和计算结果；它不替代研究设计与因果识别。助手会保留原始值、缺失状态和各次合理结果，不按显著性挑选结论。
