## 入口基线模拟

在五个项目 Skills 创建前，独立子代理只读 README、开发说明、CLI、模块入口及软件包配置，分别响应无数据方向、只有论文题名、缺失补零、无路径续接更正、仓库保存故障五个情境。
未观察到编造发现、自动补零、混淆利润率与波动或伪称保存成功。发现公开入口需要有效 inventory 才能 guide、缺少无数据起步/文献登记/项目接续的统一引导，以及开发说明已落后于 Workspace。
这是只读情境模拟与入口缺项观察，不是两种宿主的实测，也不把缺项说成已观察到的错误研究行为。
