独立代码审查发现并修复了以下问题，每项保留失败后通过的回归检查：

1. 状态或概览的符号链接可能覆盖其他材料；布局/记录路径重叠可能破坏已登记文件。
2. 恢复旧结果后错误保留“已核对”状态；现恢复结果需重新核验。
3. 旧确认摘录或含上级路径别名的凭据可能批准新方案版本。
4. 任务/摘要可能继续消费已变更的输出版本。
5. 外部结果暴露未进入共同探索历史。
6. Git 把文件名中的方括号当匹配表达式，可能纳入未选文件；现按字面路径提交。

上述测试验证可重复的软件行为，不代表统计方法、宿主推理或教学效果已通过验收。
