# 官网交互与动态展示改进

日期：2026-09-26。维护分支：codex/framework-foundation。

目标：依据用户提供的飞书前端库教程，在现有官网加入可实际操作的研究流程和结果展示，以及与研究主题相关的首屏动效。

## 来源与选择

已通过 Safari 阅读飞书正文「可调用前端库清单」及「让图表自动停在高光观察位」：
https://vupyskvyxk.feishu.cn/wiki/IouWw3ihmihAsXkNILdc6DZ2nhc

正文列出 ECharts、Spline、Three.js、Shadertoy、Unicorn Studio、Matter.js、Rive、Mapbox。
本次采用 ECharts 的图表交互与 Three.js 的三维展示能力；自行实现研究主题与布局，不复制社区作品。
Spline / Rive / Unicorn 的成品需要逐件核实素材、授权与运行条件；物理和地图不直接服务当前官网内容，暂不纳入。

比较的方案：
1. 只增加 CSS 入场动效：改动小，但与现有渐入、聚光效果重复。
2. 保留静态网站，局部接入成熟库：本次采用，交互集中在研究流程和可追溯结果。
3. 迁移到完整前端框架及成套组件：对当前静态介绍页成本过高。

## 设计与文件边界

- `website/index.html`：保留首屏报告、原始文件入口、现有内容；添加流程控制与交互结果区。静态 HTML 仍呈现所有必要信息。
- `website/interactions.css`：研究网络、流程导航、结果图表及移动布局。
- `website/interactions.js`：流程切换、提示词联动、ECharts 延迟加载及数据说明。所有按钮支持键盘；显式操作才改变选中项。
- `website/research-network.js`：动态导入本地 Three.js，绘制抽象研究网络；无 WebGL 时保留 CSS 背景。页面隐藏或首屏离开视口时停止循环。
- `website/vendor/`：固定版本的开源前端库、对应许可证与来源记录；无外部运行时请求。
- `website/motion.js`：移除动效开关及减少动态效果逻辑，按用户本轮更正默认展示动态效果。
- `website/README.md`：新增功能、预览要求、来源与降级说明。
