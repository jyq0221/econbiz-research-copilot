# Python 默认、Stata 可选：开发验收记录

日期：2026-09-16；版本：0.2.0a2；维护分支：codex/framework-foundation。

## 能力与环境

默认 Python 正式执行及独立 Python 复核继续完整可用。显式 Stata 路径由原生 areg / Mata 生成数值，再用共享的独立 SciPy 投影、最小二乘和协方差实现复核。原始数值、实际输入与样本、脚本、日志和复核记录共同保存。统计规则不变时可以另建换引擎复现运行，保留原方案批准和全部旧结果。

本机实际环境为 macOS 26.6.2 arm64、Python 3.9.6，固定 analysis 依赖与正式分析手册一致。Stata 应用入口为 StataMP.app 内的 stata-mp，但实际批处理探针返回 **19 / IC / Unix，构建 08 Apr 2025**。记录这些实测值，不将应用名称视为 MP 数值执行证明。二进制 SHA-256 为 `889de37e673ad468298fa3ba1ea9500b2ba3b9f55434b07735d60a32d3c5b064`，官方 ado 实现摘要为 `e4987f3ca0dd0b1efc91408316d07562d2f6e9775e6c215276d36a3780ebee2f`；没有读取或打包授权文件。

## 边界

仅覆盖手册声明的 CSV/XLSX、描述统计及线性固定效应关联分析，不含 DID、IV、权重、多维聚类、原生 dta、任意已有 do-file 或第三方 Stata 命令。Stata 首批仅验收上述 macOS arm64 / 19 控制台；其他系统和版本、Claude Code 跨宿主交接及真实初学者试用另行验收。独立数值通过不认证变量构造、因果识别或小簇推断。

原生重跑要求环境身份一致；同学没有 Stata 可以读取有效历史材料，并按相同当前方案另建 Python 复现。Stata 输出超出可准确表示的浮点范围时明确拒绝，不将丢失数值精度的结果标为通过。
