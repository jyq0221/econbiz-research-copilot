## 已实现

已接通 CSV/XLSX → 盘点与明确的可执行方案 → 确认 → Python 描述统计/线性固定效应 → 独立数值复核 → Markdown/HTML/CSV 报告 → 修改后过期和重跑。验收均用临时合成数据，无个人研究数据写入仓库。

运行包固定代码、输入和环境。数值容差预设为相对 1e-6、绝对 1e-8，模型、键及计数精确比较；自由度、推断及容量口径见 [正式分析手册](research-handbook/analysis-execution.md)。

## 独立审阅与故障修复

数值规格审阅、代码质量审阅分开进行。每个发现先用失败测试复现，修复后复测；最终独立审阅无剩余问题。

- 统一实际固定效应字段名，补充逐项实际值、参考值、偏差及容差；回归也提供同样本描述统计。
- 上游字节改变或方案修订使运行过期时，仍保存冻结依赖、输出及失败日志，禁止消费。
- 接收方对实际加载的结果再次独立计算，防止改动结果后沿用旧通过标记。
- 回归结果已生成、复核超时时，保存部分输出并记录结果暴露；后续新方案不能伪装为事前计划。
- 内存不足、深层 JSON 错误、意外参考异常保留失败证据；父核验未完成时不得沿用 worker 的通过记录。
- 额外六组行序、非平衡、单例和每观测单独聚类探针对数值关系核对通过。
