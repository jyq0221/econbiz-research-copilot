# 文献卡与判断—来源表

| 字段 | 填写依据 |
| --- | --- |
| 来源及版本 | 已导入 source_id 和实际文献身份；未知信息留空 |
| 已读范围 | metadata/abstract/excerpt/full_text，以实际阅读为准 |
| 定位 | 页码、章节、表号或可定位段落，不能推测页码 |
| 对象与方法 | 已读内容中明确的样本与比较方式 |
| 判断 claim | 原文能支持的具体判断；metadata 时留空 |
| 支持 support | 必要短摘录或清楚的原文指向；metadata 时留空 |
| 限制 limits | 阅读范围、测量、对象或识别的适用边界 |
| 对本研究的影响 | 哪个设计选择受影响，属于推论还是直接证据 |

| 本项目判断 | 来源标识/版本/定位 | 支持性质 | 相反证据或待查内容 |
| --- | --- | --- | --- |
| 根据本轮问题填写 | 只填实际读到材料 | 直接/间接/理论/测量 | 没有核实则明确保留 |

以 literature_evidence 保存；来源事实和研究者推论分开写。
