# 分析与表图规划

| 项目 | 填写依据 |
| --- | --- |
| 要回答的判断 | 当前有效研究问题 |
| 方案、数据与代码版本 | 已登记的实际标识；未有代码说明未执行 |
| 样本、变量和模型选项 | 具体规则、研究理由及现有授权 |
| 当前能执行的检查 | 阶段 A 的 CSV 结构、键、缺失及数值检查 |
| 待执行及独立核验 | 阶段 B 所需样本、参数、环境和数值参考 |
| 结果字段 | 将来应报告的样本、估计量、区间和诊断，不预填数值 |
| 表图用途与来源 | 每张表/图回答什么，每个数值来自哪个实际产物 |
| 失败记录 | 实际错误位置、影响及可继续的工作 |

规划稿不属于 result。只有读取真实运行证据并完成相应核对，才能声明已执行或已复现。
