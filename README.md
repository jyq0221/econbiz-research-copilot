# 经管实证研究助手

帮助经管科研初学者，把研究兴趣、现有资料或老师意见整理成有依据的问题和方案，并保存讨论、材料与版本，方便下次继续。

**阶段 A：研究准备试用版。** 已提供研究入口、文献和数据工作方法、CSV 检查、科研记录及文件版本工具；正式回归与独立数值复核属于阶段 B。实际检查和未完成条件见 [验证记录](docs/agent-entry-validation.md)。

## 怎样开始

1. 下载或克隆本仓库，在已安装的 Codex 或 Claude Code 中打开**仓库根目录**。
2. 直接说想做什么。可以只有方向，也可以已有论文、数据、结果或老师反馈，不必先学命令或记住技能名称。
3. 助手先读已有材料，解释当前判断和下一步；需要保存一项研究时，再建立对应项目。

可以这样发第一条请求：

> 我想研究企业数字化与经营风险，目前还没有数据。先帮我明确要回答的问题，不清楚的地方保留待核实。

也可以说：

- “读这两篇论文，比较指标定义，说明哪些证据能用于我的研究。”
- “检查这份企业年度 CSV，看看重复记录和缺失值需要怎样处理。”
- “这是老师的意见，帮我比较修改方案，原方案和结果都保留。”
- “继续上次项目，先看现在做到哪里、还缺什么。”

若宿主未自动读取入口，可补充：“请按本项目 AGENTS.md 和研究入口 Skill 开始。”适配文件随仓库提供；实际兼容范围以验证记录为准。

## 现在能帮你做什么

| 当前需要 | 可以获得的帮助 |
| --- | --- |
| 只有兴趣，还没数据 | 澄清现象、区分研究目标、比较问题，保存注明缺口的概念草案 |
| 有论文或材料 | 结合宿主可用的阅读/检索能力整理证据，记录实际已读范围和位置 |
| 有企业年度 CSV | 检查键、重复、原始缺失标记及数值异常，保存完整报告 |
| 需要形成方案 | 整理问题、测量、样本和比较方式，绑定数据和证据版本 |
| 有外部回归结果 | 在明确“尚未复现”的情况下讨论单位、幅度、精度和解释范围 |
| 需要保存、修改或继续 | 保留实际材料版本、讨论更正、任务、具体版本确认和检查点 |

数据检查通过不代表指标已经测量正确，也不证明因果关系。未知项、原始缺失状态、原方案和全部结果都会保留；不以获得显著结果作为研究完成标准。

## 文件保存在哪里

真正开始研究后，默认保存在 `research-projects/项目标识/`，也可使用你明确指定的位置：

- `literature/`：文献来源和证据笔记。
- `data/`：原始材料、字段说明及后续数据产物。
- `research/`：方案、任务、决定、讨论、报告和检查点。
- `研究进展.md`：当前进展和下一步。

旧版本会保留。恢复旧稿形成新版本；材料丢失或输入改变时，会指出受影响的内容。外部索引材料的恢复仍依赖原文件可访问。

继续时从工具仓库根打开同一项目，让助手核对记录。切换宿主前结束上一次写入；未保存的聊天内容无法保证恢复。保存任务不等于后台定时执行。
