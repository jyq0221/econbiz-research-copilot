# 经管实证研究助手

帮助刚接触实证研究的经管学生，把大概的研究方向逐步变成可以用数据回答的问题，并理解分析结果说明了什么。

你可能已经下载了一份企业数据，却还不确定：“这些数据能研究什么？指标选得合适吗？下一步该做什么？”这个项目希望围绕这些问题提供帮助，让每一步都有理由、有记录，也能回头核对。

**项目目前处于早期开发阶段，已能通过中文问答准备研究路线草案，并生成浏览器可读的对照报告。问答仍需协助者启动，尚不能直接在网页上传数据或运行回归。**

可以先看 [教学报告示例](examples/student-report.html)（下载后用浏览器打开），了解报告会怎样解释路线差异、数据覆盖和下一步。

## 它希望怎样帮助你？

计划中的完整流程是：

1. **说清研究方向。** 从你关心的经济现象出发，逐步明确想回答的问题，不要求一开始就写好假设或选定模型。
2. **了解手上的数据。** 看有哪些企业、覆盖哪些年份、各列代表什么，以及缺失值是什么意思。
3. **比较可行的方案。** 说明每个方案研究什么、需要哪些数据、为什么值得做、还有哪些问题。如果数据暂时不够，也会指出需要补充什么。
4. **确认后再分析。** 把变量定义、样本选择和分析方法的理由说清楚，再按确认的方案执行。
5. **理解结果并决定下一步。** 结合估计结果及其不确定性，判断可以得出什么结论、哪些解释仍无法区分，以及是否需要补数据或调整问题。

以上是建设目标，当前完成的部分见下表。

## 现在能做什么？

| 你关心的事 | 当前进度 |
| --- | --- |
| 数据有没有明显问题？ | 已能检查同一家企业同一年是否重复、企业或年份是否缺失、数值列是否混入异常内容，并留下问题记录。 |
| 空白和“未披露”会不会被当成零？ | 已能分别记录常见缺失标记，保留原始内容，不自动填零。 |
| 研究方案能否保存并核对？ | 已能登记准备好的方案，检查引用的数据列是否存在，并记录研究者对具体版本的确认。 |
| 改了变量定义，还会不会误用旧结果？ | 已建立关联记录：修改上游内容后，相关的后续材料会被标为需要更新；原方案仍然保留。 |
| 能否从方向和数据开始准备方案？ | 已有引导式原型：核实关注现象与数据列后，按数据条件准备“描述现象”和“条件关联”草案。信息不足时列出待核实事项，不硬凑方案。 |
| 能否运行回归、解释结果？ | 尚未接入，接下来会逐步建设。 |

数据检查通过，只表示已经完成表中列出的检查。指标能否代表研究概念、样本是否合适，以及结果能否作因果解释，仍需要结合具体研究判断。

## 想参与试用，可以先准备什么？

准备下面三类材料即可开始讨论，不必先学编程：

- **一两句话的研究方向。** 例如：“想了解企业数字化程度与经营风险之间的关系，但还没有确定用什么指标。”
- **一份现有数据。** 当前检查工具适用于企业年度表格，通常一行对应一家企业的一年；实际试运行暂时只读取 CSV 格式，也就是一种常见的纯文本表格文件。
- **数据说明。** 尽量说明每一列的含义、单位、来源和年份，以及空白表示什么。不清楚的地方可以直接注明“待核实”。

目前试运行需要有人协助启动程序。之后可以按中文提示选择数据列、填写含义，并打开生成的报告一起讨论。不清楚的内容可以留空；目前使用固定的草案规则，尚不能仅凭一句研究方向自动提出新颖选题。

项目附有虚构的教学数据，用于演示检查和方案记录，不代表真实研究结论。

## 接下来会建设什么？

接下来完善草案审阅与修改，再接入描述统计和固定效应分析，逐步实现从数据、方案到结果解释的完整流程。

研究是否值得继续，将结合问题价值、测量质量和结果提供的证据来判断；不会把获得显著结果作为完成研究的标准。
