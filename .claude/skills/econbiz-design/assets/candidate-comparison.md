# 候选方案比较

| 项目 | 方案一 | 方案二（有实际不同问题时填写） |
| --- | --- | --- |
| 问题、目标与判断 | 用户现象和待回答问题 | 同左 |
| 理论、测量依据与来源 | 实际文献定位；未知写待查 | 同左 |
| 概念—字段、单位和时间 | 实际字段或明确缺口 | 同左 |
| 样本与比较 | 使用哪些观测作什么比较 | 同左 |
| 模型与成立条件 | 解释比较对象及未核实条件 | 同左 |
| 可行性和数据缺口 | 真实覆盖与工具能力 | 同左 |
| 与其他方案关系 | 不同问题、替代测量或稳健性，不能混称 | 同左 |
| 推荐顺序与理由 | 问题价值、测量质量和工作量 | 同左 |
| 结论范围 | 描述、关联、因果或预测的支持边界 | 同左 |
| 提出时点与探索原因 | 事前 planned 或结果后 exploratory | 同左 |

不强行凑方案。无数据使用 concept_plan；正式方案另以 register_plan 绑定数据和证据版本。
