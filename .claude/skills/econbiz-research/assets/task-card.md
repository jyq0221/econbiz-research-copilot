# 研究任务卡

| 字段 | 填写依据 |
| --- | --- |
| 问题与理由 | 用户当前问题及为什么需要本项工作 |
| 输入与版本 | 实际 artifact_id/version；缺少材料明确写待取得 |
| 已有授权 | 当前可见原话、适用方案和版本；没有则写未确认 |
| 预期输出 | 能回答问题的具体材料，不预写结果方向 |
| 检查方法 | 对照哪些原始字段、出处或实际产物 |
| 状态 | queued/in_progress/waiting/needs_check/completed |
| 实际输出 | 真正生成的产物标识和版本；未完成时留空 |
| 等待原因与下一步 | 缺的材料、决定或工具，以及可继续的具体工作 |

用 research_task 保存；input_versions 形成依赖，outputs 使用版本引用。格式保存成功与任务完成分开显示。
