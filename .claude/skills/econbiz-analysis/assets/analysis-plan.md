# 分析与表图规划

| 项目 | 填写依据 |
| --- | --- |
| 要回答的判断 | 当前有效研究问题 |
| 方案、数据与代码版本 | 已登记的实际标识；未有代码说明未执行 |
| 样本、变量和模型选项 | 具体规则、研究理由及现有授权 |
| 推荐方法与处理 | 问题、变量含义、数据结构及识别依据；说明缩尾、ln 等具体口径 |
| 代码与执行路径 | 内置已核验方法或 Agent 生成的 Python/Stata 项目脚本；实际入口与依赖 |
| 执行前核对 | 样本、参数、当前方案版本与授权；已有授权内自动运行和修复技术问题 |
| 检查覆盖 | 执行、数据处理、统计数值分别记录；项目脚本不自报独立核验通过 |
| 结果字段 | 将来应报告的样本、估计量、区间和诊断，不预填数值 |
| 表图用途与来源 | 每张表/图回答什么，每个数值来自哪个实际产物 |
| 失败记录 | 实际错误位置、影响及可继续的工作 |

规划稿不属于 result。只有读取真实运行证据并完成相应核对，才能声明已执行或已复现。
